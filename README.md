# ruang temu

Landing page coffee shop dan workspace berbasis Next.js App Router, TypeScript, dan Tailwind CSS.

## Development

- `npm run dev` — development server
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript check
- `npm run build` — production build

Informasi bisnis yang belum terverifikasi disimpan sebagai `null` dalam `src/content/site.ts` dan tidak ditampilkan sebagai data final.
